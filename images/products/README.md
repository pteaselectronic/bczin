# Product images

Save product photos in the folder that matches the product detail page category.

```text
images/products/
|-- cameras/
|-- lenses/
|-- tripods/
|-- lighting/
|-- audio-video/
|-- bags/
|-- accessories/
`-- drones/
```

Use clear lowercase filenames with hyphens. Include the product model and view when useful.

```text
sony-a7-iv-front.jpg
sony-a7-iv-back.jpg
canon-rf-50mm-f1-8-side.jpg
```

Recommended image formats are `.jpg` for photos, `.png` for transparent images, and `.webp` for smaller web-ready files.
